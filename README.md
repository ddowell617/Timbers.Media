# Timbers Media

Timbers Media is the public open-source Drupal media foundation for the Timbers and Kinnect ecosystem.

It provides reusable, provider-neutral media foundation capabilities for Drupal projects, including metadata extraction, metadata normalization, import framework foundations, provider abstraction, Flysystem integration helpers, file utilities, conversion foundation contracts, and community DAM foundations.

## Architecture and Ownership

Authoritative capability ownership is defined in Timbers Infrastructure:

`docs/architecture/media/capability-boundaries.md`

This repository intentionally references that governing document instead of duplicating ownership rules.

## Scope

Timbers Media focuses on open-source media foundations.

Enterprise media intelligence, AI recognition, provenance, privacy/trust workflows, preservation policy, advanced orchestration, Media Knowledge Graphs, enterprise UX, mobile integration, federation, and MIR runtime execution remain Kinnect capabilities.

## Status

Repository bootstrap is complete.

Initial implementation work will begin with reusable media foundation capabilities that have validated open-source ownership.
