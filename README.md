# Timbers Media

Timbers Media is the open-source Drupal media foundation for the Timbers and Kinnect ecosystem.

It owns reusable community-oriented media capabilities such as metadata extraction, import framework foundations, provider abstraction, Flysystem integration helpers, EXIF helpers, and community DAM foundations.

Enterprise media intelligence, AI recognition, provenance, preservation policy, enterprise workflows, and MIR execution remain outside this repository.
