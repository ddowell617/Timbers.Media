# TMM.100 — Timbers Media Repository Bootstrap

## Status

In progress.

## Objective

Create the dedicated Timbers Media repository as the long-term home for reusable open-source Drupal media foundation capabilities.

## Initial Scope

Allowed:

- metadata extraction
- import framework foundations
- provider abstraction
- Flysystem integration helpers
- EXIF helpers
- community DAM foundations

Excluded:

- AI recognition
- provenance
- preservation policy
- enterprise workflows
- enterprise UX
- enterprise reporting
- MIR runtime execution

## Governance

Timbers Media must remain suitable for open-source Drupal community use.

Enterprise-specific capabilities remain in Kinnect Platform.
Runtime execution remains in Kinnect MIR.
