# Timbers Media Governance

## Purpose

Timbers Media is the public open-source Drupal media foundation for reusable community-oriented media capabilities.

## Authoritative Architecture

Authoritative ecosystem architecture and capability ownership are defined in Timbers Infrastructure.

Primary governing document:

- `docs/architecture/media/capability-boundaries.md` in Timbers Infrastructure

This repository should reference governing architecture rather than duplicate it.

## Repository Scope

Timbers Media accepts reusable, open-source, provider-neutral media foundation capabilities.

## Exclusions

Timbers Media does not own proprietary Kinnect capabilities such as AI recognition, provenance, privacy/trust workflows, preservation policy, advanced orchestration, Media Knowledge Graphs, enterprise UX, mobile integration, federation, or MIR runtime execution.

## Branch Strategy

- `main` is the stable default branch.
- Feature work should occur in short-lived feature branches.
- Releases should be tagged after validation.

## Documentation Strategy

Repository-local documentation should explain implementation and usage.

Architecture, ownership, and ecosystem governance remain in Timbers Infrastructure.
